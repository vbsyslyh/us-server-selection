## 线路怎么选：AS4837、AS9929、CN2 GIA 分别适合谁

美国服务器的回国线路决定了晚高峰稳不稳。几个常见代号的含义：

- **CN2 GIA（AS4809）**：中国电信精品国际出口，负载低，晚高峰稳定，价格贵，只有电信用户走这条线。
- **AS9929**：中国联通工业互联网骨干网，联通回程质量好，带宽通常给得大。
- **CMIN2（AS58807）**：中国移动精品回程，移动用户友好。
- **AS4837**：联通 169 骨干网，属于普通国际线路，便宜，晚高峰容易波动。
- **普通 BGP / 国际线路**：靠国际出口互联，价格最低，稳定性看机房。

选择判据只有三条：用户以电信为主，优先 CN2 GIA；以联通为主，优先 AS9929；面向海外用户而不是国内回连，机房位置和带宽比回国线路更重要。

雨云美国洛杉矶二区走 CMI + AS9929，对联通和移动用户更友好；一区走 AS4837，价格便宜但晚高峰表现一般。大带宽版具体落在哪个区，公开资料没有写明，下单前要跟客服确认，或者先用测试 IP 跑一下晚高峰延迟。

市面上有两种产品思路。华纳云、A5数据走的是一台机器三网直连，比如 A5数据把 CN2GIA + CUPM9929 + CMIN2 打包成“三网精品”，华纳云是 CN2 + CUG + CMI。狗云则把电信和联通拆到两个机房：洛杉矶走 CN2 GIA，圣何塞走 AS9929。一台机器覆盖三网省事，分机房专精单线路更纯，两种都能用，看你用户主要在哪家运营商。

## 退款、实名、备案、IP：下单前确认的四件事

**退款。** 雨云提供 7 天无理由退订，每个账号最多 3 次，退款退到账户余额，不是原路退回。这意味着你试错成本低，但退回来的钱只能在雨云继续消费。狗云的规则是余额充值一个月内原路退回，经典云开通三日内可申请销毁退款，条件是 IP 未变更、流量不超过 5%。两家规则不同，买之前看清楚退到哪里、几天内有效。

**实名与备案。** 国内云服务商都要求实名认证，雨云绑定微信或上传身份证即可。国内机房要域名备案才能绑定域名，美国、香港、日本等海外机房免备案。买美国服务器的人多数是冲免备案去的，这一条雨云是满足的。

**IP 性质。** 原生 IP 和广播 IP 是两回事。HopeIDC 明确说自己的美国服务器用的是广播 IP，查询归属地可能显示其他地区，不承诺 100% 访问有特定要求的网站，建议用 ipip.net 判断归属。雨云美国节点是否原生 IP，公开资料没有明确说明，做跨境电商、地区限制内容测试这类对 IP 归属敏感的业务，下单前必须问清楚。

**防御额度。** 雨云美国大带宽版是否带 DDoS 防御、带多少，公开资料没有写。竞品这边，华纳云和 A5数据赠 20G 防御，idcl 标 10G，HopeIDC 赠 1G 或 10G。如果你的业务容易挨打，防御额度要单独确认，不能默认云服务器自带高防。
